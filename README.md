# 羽毛球姿势教练 · 手机 App（PWA）

手机相机拍摄或相册照片 → MediaPipe Pose 识别 33 个人体关键点 → 输出 5 项动作评估与改进建议。

在线地址：https://43qjpyqh.qwenwork.host/

## 在手机上使用

1. 用手机浏览器（推荐 Chrome / Edge / Safari）打开上面的地址
2. 允许摄像头权限
3. 安卓 Chrome：菜单 → **添加到主屏幕**；iOS Safari：**分享 → 添加到主屏幕**，即可像原生 App 一样全屏启动，并支持离线打开界面

## 界面结构（同一时刻只出现一个主按钮）

| 状态 | 画面上方 | 主按钮 | 次按钮 |
| --- | --- | --- | --- |
| 未开始 | 取景提示 | 拍照分析 | 改从相册选照片 |
| 取景中 | 实时相机 +「取景中」标签 | 拍下这一拍 | 隐藏 |
| 出结果 | 骨骼标注图 +「分析结果」标签 | 重新拍摄 | 改从相册选照片 |

结果区分两层：先给 **动作评分 x/5** 与最该改的一项，再列 **逐项点评与建议**。

## 评估项

- 击球侧肘关节角度：挥拍是否充分伸展
- 击球点高度：手腕是否高于肩部
- 击球侧膝关节角度：是否屈膝降重心
- 躯干倾斜：身体平衡
- 非持拍手：是否上举辅助瞄准与平衡

## 技术

- `@mediapipe/tasks-vision`（pose_landmarker_lite，GPU 优先、CPU 自动回退）

- 静态 PWA：`manifest.webmanifest` + `sw.js`（离线缓存应用外壳与模型）

- 照片与视频帧只在设备本地处理，不会上传服务器
